# 🐟 大肥鱼桌宠（Big Fat Fish Desktop Pet）

一只 **Q 版蓝发鲸鱼娘**住在你的桌面上：只吃白饭、不干活，会自己溜达、被戳会说话、饿了自己掏铁盆干饭。

* **角色与动画 100% 来自你的立绘图片**，程序只负责播放，不手绘（`tools/make_anim.py` 用一张图生成呼吸/摆动动画帧）
* 纯 **C# WinForms + GDI+** 手写，逐像素透明分层窗口，**零第三方依赖**
* 功能参照本机安装的「天选姬 4.7.6」（华硕天选笔记本官方桌宠）

---

## 1. 怎么启动

| 方式 | 操作 |
| --- | --- |
| 桌面快捷方式 | 双击「大肥鱼桌宠」 |
| 项目目录 | 双击 `启动大肥鱼.bat` |
| 直接跑 | 双击 `bin\大肥鱼桌宠.exe` |
| 重新编译 | 双击 `重新编译.bat` |

> 需求：Windows 10/11 自带的 .NET Framework 4.x，**不需要管理员权限**。
> 项目在 `D:\其他\deepseek\大肥鱼`，不在 DSH 安装目录里，DSH 更新不会动它。

**操作方式**

| 操作 | 效果 |
| --- | --- |
| **左键单击** | 摸头：她会开心、冒气泡说话、亲密度 + |
| **左键拖动** | 把她拎起来（在空中手忙脚乱），松手后慢慢"沉"回屏幕底部 |
| **滚轮** | 缩放大小（35% ~ 250%） |
| **右键** | 打开全部功能菜单 |
| **双击** | 默认打开菜单，可改成 喂食小鱼干 / 说话 / 开始专注 / **投喂白米饭** |
| **托盘图标双击** | 显示 / 隐藏桌宠（托盘右键也有菜单） |

她会自己做的事：在屏幕底部**走来走去**、撞到屏幕边缘转晕、随机说话 / 转圈 / 欢呼、**饿了自己掏铁盆扒白饭**、你离开电脑超过 5 分钟她会睡着，你回来她会被闹醒。

## 2. 立绘与动画（角色来源）

角色完全由 `assets\sprites\` 里的图片决定，缺动作就用 `idle` 顶上。

```
assets\sprites\
├─ idle.png          静态立绘（本项目的角色就是它）
├─ happy.png         开心（同一张图的副本，可替换成别的表情）
└─ anim\             动画帧（程序按帧播放）
   ├─ idle_00.png … idle_11.png        呼吸 + 头发摆动 + 鲸鱼尾摆动
   ├─ walk_00.png …                    走路倾摆（振幅更大）
   ├─ sleep_00.png … / drag_00.png … / happy / sad / focus / relax / sick / cheer / dizzy / surprise / eat
   └─ manifest.txt                     每个动作的帧数与帧率
```

**换角色 / 加表情**：
1. 把新的透明 PNG 放进 `assets\sprites\`（文件名对应动作），右键菜单 → 角色外观 → **重新扫描立绘**；
2. 想让它动起来，用生成器做动画帧：
   ```powershell
   python tools\make_anim.py --in assets\sprites\idle.png --outdir assets\sprites\anim --frames 12 --tail "470,235,560,380"
   ```
   `--eye` / `--tail` 是眼睛和鲸鱼尾的矩形（做局部变形用），按你的图量一下即可。

**抠图工具**（把带背景的插画转成透明立绘）：
```powershell
python tools\cutout.py --in 原图.jpg --out assets\sprites\idle.png --mode white --crop 0,645,1272,1700 --erase 0,0,1272,300 --trim --max 560 --checker 校验图.png
# --mode white 纯色背景 / color 花色背景 / sharp 虚化背景 / poly 手工多边形
```

**图标**：`python tools\make_icon.py --in assets\sprites\idle.png --out assets\fish.ico`（从立绘头部裁切，exe 与托盘都用它）

## 3. 招牌动作：铁盆扒白米饭

* 菜单第一项 **投喂白米饭（铁盆）**，或把双击行为设成"投喂白米饭"
* 四段动作：**咀嚼** → **扒拉** → **端起铁盆往嘴里倒** → **放下舔盆**；盆里的饭量真实递减（1.0 → 0）
* 每盆 +30 饱食度、+2.2 亲密度；连吃 5 盆奖励 1 颗鱼丸
* **没人投喂时她饿了会自己掏盆**（饱食度低于 30 且冷却结束）
* 表情包面板里也能选「铁盆扒白饭」导出 PNG

## 5. 系统监控说明

| 指标 | 来源 | 备注 |
| --- | --- | --- |
| CPU 占用 | `GetSystemTimes` | 1 秒采样 |
| 内存 | `GlobalMemoryStatusEx` | 已用 / 总量 |
| 网络 | `NetworkInterface` 收发字节增量 | 自适应 KB/s、MB/s |
| 磁盘 / 电池 / 开机时长 / 进程数 | `DriveInfo` / `GetSystemPowerStatus` / `GetTickCount64` | 低频采样 |
| GPU 占用 / 温度 / 风扇 / 显存 | `nvidia-smi` | 需要 NVIDIA 驱动（本机 RTX 5060 实测正常） |
| CPU 温度 | ACPI 热区 `MSAcpi_ThermalZoneTemperature` | 部分机型不开放，取不到显示 `--` |

联动台词：温度 ≥88°C 或占用 ≥95% → 她会"发烧"并提醒散热；电量低会犯困，插电会说"充能"。

## 6. 存档与数值

* **饱食度**：随时间下降，投喂 +30/+22，低于 25 喊饿，低于 18 委屈
* **亲密度**：摸头 / 投喂 / 完成番茄都会涨，每 20% 升级播报
* **鱼丸**：完成 1 个番茄 +1，陪伴满 20 分钟 +1，连喂 5 次 +1；扭蛋消耗 1 颗（重复退还）
* 存档目录（自动选可写位置）：`%APPDATA%\BigFatFish\` → 不可写时退到 `%LOCALAPPDATA%\BigFatFish\` → 再退到 `bin\data\`
  里面是 `config.ini`（设置）+ `save.ini`（养成进度），删掉 `save.ini` 即可重置

```
├─ assets/

│  ├─ Native.cs          Win32 逐像素透明分层窗口

│  ├─ BubbleArt.cs       台词气泡（严格不越界）

│  ├─ Speech.cs          台词库、鱼报文案

│  ├─ PetBrain.cs        状态机、漫游、下沉物理、系统联动、养成统计

```

### 自检参数（排障用）

```powershell
bin\BigFatFish.exe -shot 出图.png -pose rice      # 用真实渲染管线导出一帧（idle/rice/sleep/focus/drag/sick/walk）
bin\BigFatFish.exe -diag 报告.txt                 # 输出窗口几何、提交结果、存档目录
bin\BigFatFish.exe -pos 300,400                   # 本次启动临时指定位置（不写回配置）
bin\BigFatFish.exe -style sprite                  # 本次启动临时强制用立绘（也不写回配置）
```

## 8. 已知限制

* **只有一张立绘（上半身）**，动作是"同一张图的变形动画"：呼吸、头发/鲸鱼尾摆动、整体倾摆。要更丰富的动作，给我更多透明 PNG（不同表情/姿势），放进 `assets\sprites\` 重跑 `make_anim.py` 即可。
* 单张图做**眨眼**会糊（眼睛上方是刘海、下方是脸颊阴影），所以没做眨眼；有"闭眼"立绘就能直接支持。
* **鼠标穿透**开启后点不到她，只能用托盘图标关掉（菜单里有提示）。
* 环境音是**算法合成**的（滤波噪声/正弦啁啾），零素材、可循环，音色偏简约。
* CPU 温度、GPU 数据取决于系统与驱动；拿不到显示 `--`，不影响其它功能。
* 与天选姬**可以同时运行**；不想同时跑就在奥创中心里关掉天选姬。
